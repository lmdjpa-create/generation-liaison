Installer l’application sur Android

Le plus simple : ouvrir l’application en ligne, sans installer de fichier. Si vous préférez l’application Android, suivez ces trois étapes. Les écrans et leurs noms peuvent varier selon votre téléphone.

  1. 1. Télécharger le fichier

    Depuis le site officiel de Génération Liaison, touchez « Télécharger l’application Android ». Ouvrez ensuite le fichier téléchargé dans les notifications ou dans « Téléchargements ».

  2. 2. Vérifier la source

    Android peut afficher un avertissement parce que le fichier ne vient pas du Play Store. Si vous avez bien téléchargé le fichier depuis le site officiel, le téléphone peut vous proposer d’autoriser cette source dans ses paramètres. Ne l’autorisez pas si vous avez un doute.

  3. 3. Installer, puis ouvrir

    Revenez au fichier si nécessaire, touchez « Installer », puis « Ouvrir ». Vous pouvez ensuite désactiver l’autorisation d’installation pour cette source dans les paramètres du téléphone.

En cas de doute : si l’origine du fichier est incertaine ou si une alerte de sécurité vous inquiète, ne poursuivez pas. Utilisez plutôt la version en ligne ou contactez support@generation-liaison.fr. Ne désactivez pas les protections de votre téléphone.
